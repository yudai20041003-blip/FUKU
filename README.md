# 👔 毎日のファッションコーディネートアプリ

天気、行き先、好みのスタイルに基づいて、最適なファッションコーディネートを提案するStreamlitアプリです。

## ✨ 主な機能

### 1. 🌤️ 天気連動コーディネート提案
- OpenWeatherMap APIを使用してリアルタイムの天気情報を取得
- 気温、湿度、風速に基づいた服装の推奨
- 天気に応じたアウター、トップス、ボトムスの自動選択

### 2. 👗 ワードローブ管理
- 自分が持っている服のデータベース管理
- カテゴリー別（アウター、トップス、ボトムス、靴、アクセサリー）の整理
- 色、ブランド、スタイル、季節ごとの分類
- サンプルデータでの動作確認も可能

### 3. 🎯 スタイル別提案
対応スタイル：
- **カジュアル**: リラックスした日常的なスタイル
- **ストリート**: 都市的でトレンド感のあるスタイル
- **シティ**: スマートで洗練された都会的なスタイル
- **フォーマル**: ビジネスやフォーマルシーンに適したスタイル
- **アメカジ**: アメリカンカジュアルスタイル
- **モード**: ファッション性の高いアーティスティックなスタイル

### 4. 📍 シーン別提案
行き先に応じた最適なコーディネート：
- 仕事・オフィス
- デート
- カフェ・友達と
- ショッピング
- アウトドア
- パーティー

### 5. ✨ インスピレーション取得
- **Pinterest**: 選択したスタイルの自動検索リンク生成
- **Instagram**: ハッシュタグ検索で最新コーデをチェック

### 6. 🛍️ ショッピングサポート
以下の公式サイトから類似商品を検索：
- ユニクロ
- GU
- ZOZOTOWN
- ZARA
- H&M
- 無印良品

#### 機能詳細：
- スタイル別に不足しているアイテムの提案
- お手頃な価格帯のブランド検索
- 各ブランドの価格帯情報表示
- 予算に応じたショッピングのコツ

### 7. 📊 コーディネート履歴 (NEW!)
- 過去のコーディネートを自動保存
- 評価機能（0-5段階）で気に入ったコーデを記録
- メモ機能で感想やシーンを記録
- 統計情報の表示（スタイル分布、行き先分布など）
- お気に入りコーディネートの一覧表示
- 履歴の検索と削除

### 8. 💾 データ管理 (NEW!)
- ワードローブと履歴のエクスポート（JSON/ZIP形式）
- データのインポート機能
- バックアップと復元の簡単な操作
- データの妥当性検証

## 🚀 セットアップ

### 必要要件
- Python 3.8以上
- pip

### インストール

1. リポジトリをクローン
```bash
git clone <repository-url>
cd webapp
```

2. 依存パッケージをインストール
```bash
pip install -r requirements.txt
```

3. 環境変数の設定（リアルタイム天気情報を使用する場合）
```bash
cp .env.example .env
```

`.env`ファイルを編集して、APIキーを設定：
- `OPENWEATHER_API_KEY`: OpenWeatherMapのAPIキー

**OpenWeatherMap APIキーの取得方法：**
1. [OpenWeatherMap](https://home.openweathermap.org/users/sign_up)でアカウント作成
2. メールアドレスを確認
3. [API Keys](https://home.openweathermap.org/api_keys)ページでAPIキーを取得
4. `.env`ファイルに貼り付け：`OPENWEATHER_API_KEY=あなたのAPIキー`
5. アプリを再起動

**注意**: 
- APIキーがない場合でも、デモデータ（固定気温20度）で動作します
- APIキーは無料で、60回/分、1,000,000回/月まで使用可能
- APIキーが有効になるまで最大2時間かかる場合があります

## 📱 使い方

### アプリの起動

```bash
streamlit run app.py
```

ブラウザが自動的に開き、アプリが起動します（通常は http://localhost:8501）。

### 基本的な使用手順

#### 1. ワードローブの登録
1. 左メニューから「👗 ワードローブ管理」を選択
2. 「➕ アイテム追加」タブで持っている服を登録
   - または「🔧 管理」タブで「サンプルデータをロード」してデモを試す

#### 2. コーディネート生成
1. 「🏠 ホーム」に戻る
2. サイドバーで以下を設定：
   - 📍 場所（都市名）
   - 🎯 今日の予定（行き先）
   - 👕 好みのスタイル
3. 「🎨 コーディネート生成」ボタンをクリック

#### 3. インスピレーション探し
- 生成されたコーディネートの下に、PinterestとInstagramのリンクが表示されます
- クリックして似たようなコーディネートを探せます

#### 4. 新しい服を探す
1. 「🛍️ 新しい服を探す」を選択
2. 「🎯 スタイル別提案」タブで：
   - 目指したいスタイルを選択
   - 「提案を見る」で不足しているアイテムを確認
   - 各ブランドのリンクから商品を検索
3. 「🔍 カスタム検索」タブで：
   - 探している具体的なアイテムを検索

## 🔑 APIキーについて

**重要：APIキーがなくても完全に動作します！**

- 天気情報：APIキーがない場合、ダミーデータを使用
- すべての機能がAPIキーなしで利用可能
- 必要に応じて後から追加可能

リアルタイムの天気情報を使用したい場合のみ、OpenWeatherMap APIキー（無料）を設定してください。
